## 使用方法

1. **第一遍**（投递后当天）：读 01、02，把自我介绍背到脱口而出。
2. **第二遍**（约面试后）：逐册精读 03–10、12，每道问答先自己答一遍再看参考框架。
3. **第三遍**（面试当天）：只看 11 速记卡 + 自己标注的薄弱册。

## 三条贯穿全程的定位（先记住这个）

1. **你是甲方，不是乙方。** 所有回答的主语要换成"我们公司""业务部门"，价值口径换成"业务效益、成本、合规、效率"，而不是"交付了项目""上线了系统"。
2. **你不写代码，但你要有技术判断力。** JD 原话："能说清为什么选它不选另一个"。你的武器是 18 年技术底子 + 4 年制造业 MES 实施—— vendor 骗不过你，这是你最大的差异化。
3. **化工 + 国有控股 + 安义县 = 三个关键词。** 化工决定了安全环保是红线、生产连续性是生命线；国有控股决定了流程规范和"一把手支持"的重要性；安义县决定了他们最担心你能不能待得住——每个问题都要顺带消解他们的顾虑。

## 事实核对说明

- 公司基础信息来自公开渠道（化工招聘网公司简介、裁判文书网、投融界、行业期刊论文），**部分资料年代较早**，涉及公司人事、上市进展的均标注 `[面试时确认]`，不要在面试中当作已验证事实说出。
- 行业知识（锆化工工艺、化工 MES、等保 2.0 等）为通用行业知识，可用于回答，但涉及对方公司具体情况时用提问确认，不要替面试官下结论。
